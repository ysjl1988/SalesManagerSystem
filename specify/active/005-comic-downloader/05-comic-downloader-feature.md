## 1. 需求描述

### 1.1 背景
系统需要增加一个仅管理员可用的漫画下载管理功能，用于从网页自动识别并下载漫画内容，方便统一管理和查看。

### 1.2 功能要求

#### FR1: 权限控制
- 仅管理员角色（role='ADMIN'）可以访问漫画管理菜单和功能
- 普通用户无法看到相关入口，直接访问URL应被重定向并提示权限不足

#### FR2: 漫画下载
- 支持输入漫画网页URL，系统自动识别漫画内容
- 自动提取漫画标题、描述、章节列表
- 自动下载各章节的图片内容
- 支持自定义漫画标题（可选，留空则自动识别）

#### FR3: 下载管理
- 显示所有漫画下载任务列表
- 实时显示下载进度（百分比、已下载/总章节数）
- 支持按状态筛选（等待中/下载中/已完成/失败）
- 支持按标题搜索
- 支持删除已下载的漫画（同时清理本地文件）
- 支持重试失败的下载任务

#### FR4: 漫画阅读
- 章节列表展示
- 阅读器支持翻页（上一章/下一章）
- 键盘快捷键支持（左右箭头键）
- 图片懒加载优化

#### FR5: 文件存储
- 每部漫画独立文件夹存储
- 章节按序号分文件夹存放
- 封面图单独保存

### 1.3 验收标准

| 编号 | 验收项 | 验收标准 | 优先级 |
|------|--------|----------|--------|
| AC1 | 权限控制 | 普通用户看不到漫画管理菜单，访问URL被拦截 | P0 |
| AC2 | 添加下载 | 输入有效URL后成功创建下载任务 | P0 |
| AC3 | 进度显示 | 下载过程中实时显示进度百分比 | P0 |
| AC4 | 漫画查看 | 下载完成后可正常查看章节和图片 | P0 |
| AC5 | 删除功能 | 删除漫画后本地文件被清理 | P0 |
| AC6 | 筛选搜索 | 筛选和搜索功能正常工作 | P1 |
| AC7 | Cloudflare网站 | 支持下载Cloudflare保护的网站 | P1 |

### 2.2 技术选型
- **网页解析**: BeautifulSoup4 + lxml

## 3. 实现方法

### 3.1 已完成实现

#### 3.1.1 数据模型 (app/models/comic.py)
- Comic 模型：漫画基本信息
- ComicChapter 模型：章节信息
- 关联关系：一对多（一部漫画有多个章节）

#### 3.1.2 下载器 (app/comic_downloader.py)
- ComicDownloader 类
- 功能：
  - `add_download_task()`: 添加下载任务
  - `_download_comic()`: 后台下载主流程
  - `_find_chapters()`: 智能识别章节列表
  - `_find_all_images()`: 提取页面图片
  - `_download_image()`: 单图片下载
  - `delete_comic()`: 删除漫画及文件
  - `_fetch_with_playwright()`: 使用浏览器绕过Cloudflare

#### 3.1.5 特殊网站支持
| 网站类型 | 处理方式 | 说明 |
|----------|----------|------|
| 普通网站 | requests | 直接HTTP请求 |
| Cloudflare保护 | Playwright | 使用浏览器自动化绕过JS挑战 |
| 18comic等 | Playwright | 需要年龄验证+浏览器访问 |

#### 3.1.3 路由 (app/routes_comic.py)
| 路由 | 方法 | 功能 |
|------|------|------|
| /comic_management | GET | 管理页面 |
| /comic/add | POST | 添加下载 |
| /comic/<id>/delete | POST | 删除漫画 |
| /comic/<id>/progress | GET | 获取进度API |
| /comic/progress/all | GET | 批量进度API |
| /comic/<id>/view | GET | 漫画详情 |
| /comic/<id>/chapter/<cid>/view | GET | 阅读章节 |
| /comic/<id>/retry | POST | 重试下载 |

#### 3.1.4 模板
- comic_management.html: 漫画网格展示、进度条、筛选
- comic_view.html: 漫画信息、章节列表
- comic_chapter_view.html: 图片阅读器、翻页导航

### 3.2 权限控制实现
- 使用 `@admin_required` 装饰器
- 模板中判断 `current_user_obj.is_admin()`
