## 📝 使用规范

### 创建新需求

```bash
# 1. 创建文件夹（序号按顺序递增）
mkdir active/002-需求名称/

# 2. 创建需求文档
touch active/002-需求名称/02-需求名称-feature.md

# 3. 编辑文档（按照模板）
```

### 文档模板

参考 [active/001-password-toggle/](./active/001-password-toggle/) 下的文档结构。

必须包含：
- 需求编号、日期、状态
- 需求描述（背景、要求、验收标准）
- 设计方案
- 实现方案
- 测试方案
- 确认记录

### 归档规则

- **归档条件**: 需求状态为"已完成"且超过2个月
- **归档路径**: `archive/年份-季度/`
- **归档示例**: `archive/2026-Q2/001-password-toggle/`
